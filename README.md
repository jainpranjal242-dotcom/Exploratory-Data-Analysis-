# Exploratory Data Analysis Project

**Student:** Pranjal Jain

Files include a full Jupyter EDA notebook, raw and cleaned CSV datasets, four visualizations, a PDF project report, and requirements.

Run with `pip install -r requirements.txt`, then open `Exploratory_Data_Analysis_Practice.ipynb` in Jupyter Notebook or VS Code and run all cells.

Dataset values are synthetic examples for educational use, not real student records.
